🎬 ScenePass — Smart Event Access Platform

ScenePass is a modern full-stack authentication project designed with a clean, cinematic-style interface. It provides a smooth Register → Login → Dashboard → Logout experience with responsive UI, smart form validation, password strength feedback, and backend API integration.

✨ Features
🔐 User Registration & Login
✅ Real-time form validation
💪 Password strength indicator
👁️ Show/Hide password
⚡ Axios API integration
🖥️ Node.js + Express backend
📊 Personalized dashboard
🚪 Secure logout flow
📱 Responsive modern design
🎨 Animated glass-style UI
🛠️ Technologies

React.js • Vite • CSS • Axios • Node.js • Express.js
