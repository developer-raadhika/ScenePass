🎬 ScenePass

ScenePass is a modern full-stack authentication web application built with React, Vite, Node.js, and Express. It provides a smooth Register → Login → Dashboard experience with a responsive and animated interface.

✨ Features
🔐 User Registration & Login
📧 Email & password validation
💪 Password strength indicator
👁️ Show/Hide password
⚡ Axios API integration
🖥️ Node.js + Express backend
🚨 Login & registration error handling
📱 Responsive design
🎨 Modern animated UI
👤 Personalized dashboard
🚪 Logout functionality
🛠️ Technologies

Frontend: React, Vite, Axios, CSS
Backend: Node.js, Express, CORS
